share address c0001624; the nm output above shows ex_unaligned_fixup is
that same address.

Reading:
  c000163c  addik r15, r0, 5704   ; with the imm prefix: r15 = 0xc0001648
  c0001640  addik r1, r1, -32     ; reserve the ABI argument save area
  c0001648  brid  -> 0xc000667c   ; == bad_page_fault (nm above)
  c000164c  nop                   ; delay slot
  c0001650  addik r1, r1, 32      ; restore -- rtsd r15, 8 returns to
                                  ; r15+8 = 0xc0001650, exactly here
  c0001658  bri   -> 0xc00057b0   ; == ret_from_exc (nm above)

Every branch target and the return-address arithmetic check out
against the symbol table.  This path is not reachable from a normal
boot (kernel-mode unaligned access whose byte-wise fixup load
faults), so this static check is the verification of record;
dynamic coverage would need a fault-injection test.
